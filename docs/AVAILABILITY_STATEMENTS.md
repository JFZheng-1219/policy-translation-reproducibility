# Manuscript availability statements

The statements below use the public, version-specific Zenodo records for the deposited data and analysis code.

## Data availability

The derived data supporting the findings of this study are available in Zenodo at `https://doi.org/10.5281/zenodo.24358131`. The deposited record contains metadata for the policy corpus, document-level large-language-model-derived policy-alignment results, city-level policy-translation-pattern classifications, figure source data, and the analysis-ready dataset used for the M1–M6 regression analyses. The original policy documents were obtained from the official websites of the relevant Chinese provincial and municipal governments. City-level GDP per capita data were compiled from statistical yearbooks issued by the relevant municipal statistics authorities; general access guidance for subprovincial statistics is provided by the National Bureau of Statistics of China at `https://www.stats.gov.cn/zs/tjws/tjzn/202301/t20230101_1903751.html`. City-level carbon-emissions data were obtained from the China Emission Accounts and Datasets (CEADs) city-level data portal at `https://www.ceads.net/data/carbon-inventory/city-level/`.

## Code availability

The custom Python and Stata code used in this study is available at `https://github.com/JFZheng-1219/policy-translation-reproducibility` and is archived in Zenodo at `https://doi.org/10.5281/zenodo.24359233`. The repository contains the prompts and scripts used for superior-policy matching, four-dimensional policy summarization and alignment scoring, together with the code for the M1–M6 statistical analyses. The exact processed datasets used to generate the reported figures and statistical results are included in the associated data record. The Python scripts require a user-supplied OpenAI API key; no credentials are included. Exact model identifiers and reasoning settings are recorded in the scripts.

For *Nature Cities*, place `Code availability` as a separate section after `Data availability` and before the references.
